# Бот-подборщик комнат из Telegram-каналов

Скрипт читает публичные Telegram-каналы из твоего списка через их открытую
веб-версию (без логина и без my.telegram.org!), ищет новые посты по заданным
параметрам и присылает тебе подборку через бота.

## Как это устроено

- `room_bot.py` заходит на `t.me/s/имя_канала` — это открытая веб-страница
  с последними постами публичного канала, читать её может кто угодно, без
  авторизации.
- `config.json` — список каналов и параметры фильтра. Редактируется без
  правки кода.
- `state.json` создастся сам — в нём бот запоминает, какие посты уже
  присылал, чтобы не дублировать.
- Бот через @BotFather присылает тебе готовую подборку в личку.

## Шаг 1. Установка библиотек

Открой PowerShell, перейди в папку с ботом:

```
cd Downloads\room_bot
pip install -r requirements.txt
```

## Шаг 2. Данные бота (это ты уже сделала)

У тебя должны быть:
- **токен бота** от @BotFather
- **твой chat_id** от @userinfobot

`api_id`/`api_hash` с my.telegram.org **больше не нужны** — эта версия
скрипта их не использует.

## Шаг 3. Впиши данные в PowerShell

```
$env:TG_BOT_TOKEN="твой_токен_бота"
$env:TG_MY_CHAT_ID="твой_id"
```

Эти переменные держатся, пока открыто окно PowerShell. Если хочешь, чтобы
сохранялись навсегда — скажи, покажу команду `setx`.

## Шаг 4. Запусти

В том же окне PowerShell:

```
python room_bot.py
```

Логина и кода из Telegram теперь не будет — скрипт сразу пойдёт читать
каналы и пришлёт тебе сообщение от бота. Если каналов совпадений не найдёт —
пришлёт "На сегодня новых подходящих объявлений не найдено".

## Шаг 5. Параметры поиска — `config.json`

```json
{
  "channels": ["nebabushkin_msk", "ugnest_msk", ...],
  "filters": {
    "keywords_include": ["сдам"],
    "keywords_exclude": ["куплю", "ищу", "студи"],
    "price_min": 70000,
    "price_max": 100000,
    "rooms": [2],
    "districts": [],
    "metro_max_minutes": 15
  }
}
```

- `channels` — юзернеймы каналов без @.
- `keywords_include` — пост должен содержать хотя бы одно из этих слов.
- `keywords_exclude` — если есть хоть одно из этих слов, пост отбрасывается.
  Используй основу слова без окончания (`"студи"` вместо `"студия"`), чтобы
  ловить все падежи.
- `price_min`/`price_max` — диапазон цены.
- `rooms` — нужное число комнат, например `[2]`.
- `districts` — если список не пуст, в тексте должен упоминаться район.
- `metro_max_minutes` — мягкое условие: если время до метро указано и больше
  этого числа — пост отбрасывается; если не указано вообще — пост проходит.

## Шаг 6. Расписание — Планировщик заданий Windows

1. Открой **Планировщик заданий** (через поиск в Пуске: "Планировщик заданий")
2. Справа нажми **"Создать задачу"**
3. Вкладка "Общие": впиши имя, например "Поиск комнат"
4. Вкладка "Триггеры" → "Создать" → выбери "Ежедневно", время начала — например
   9:00, и поставь галочку "Повторять каждые" → 3 часа, в течение — 12 часов
5. Вкладка "Действия" → "Создать" → "Запуск программы":
   - Программа: путь до `python.exe` (узнать: в PowerShell написать `where python`)
   - Аргументы: `room_bot.py`
   - Рабочая папка: путь до папки `room_bot` (например `C:\Users\Alexandra\Downloads\room_bot`)
6. Сохрани

⚠️ Планировщик запускает задачи без переменных, заданных через `$env:` в
PowerShell — их нужно один раз задать через `setx`, чтобы они сохранялись
для системы:

```
setx TG_BOT_TOKEN "твой_токен_бота"
setx TG_MY_CHAT_ID "твой_id"
```

После этого перезапусти PowerShell (и, если Планировщик уже был открыт —
пересоздай задачу), чтобы переменные подхватились.

Если запускаешь установку через `setup_room_bot.ps1` — он создаёт сразу
обе задачи Планировщика: `RoomBot` (шаг 6 выше) и `RoomBotListener`
(см. Шаг 7 ниже) и сам просит токен/chat_id, если они ещё не сохранены.

## Шаг 7. Команды и кнопочное меню в чате с ботом

Кроме автоматической подборки по расписанию, фильтры можно менять прямо
в переписке с ботом — без правки `config.json`.

**Кнопка снизу экрана** «⚙️ Настроить фильтры» открывает меню, где тапами
выбираются бюджет и тип жилья (можно несколько вариантов сразу). Кнопка
«Применить» сразу присылает всё подходящее за последние 2 суток.

**Текстовые команды:**

```
/price мин макс       — диапазон цены, например /price 0 50000
/metro минуты          — макс. время до метро пешком
/rooms 1,2              — сколько комнат подходит (0 — сбросить)
/districts район1,район2 — районы (0 — сбросить)
/keywords слово1,слово2  — ключевые слова (полностью заменяют текущие)
/exclude слово1,слово2   — слова-исключения (полностью заменяют текущие)
/addchannel имя_канала   — добавить канал
/removechannel имя_канала — убрать канал
/channels                — показать список каналов
/filters                 — показать текущие фильтры
/help                    — это сообщение
```

Эти команды и меню обрабатывает **отдельный непрерывный процесс**
(`python room_bot.py --listen`), а не тот же скрипт, что ищет объявления
по расписанию. `setup_room_bot.ps1` регистрирует его как задачу
`RoomBotListener` (запуск при входе в Windows, сам перезапускается, если
упадёт). Если меню/команды не отвечают — проверь в Планировщике заданий,
что задача `RoomBotListener` существует и в состоянии "Выполняется".

## Альтернатива Шагам 6-7: деплой в облако (Linux VM)

Вместо Планировщика заданий Windows бота можно держать на бесплатной
виртуалке в облаке — тогда он работает всегда, независимо от того,
включён ли твой компьютер. Оба процесса (`RoomBot`-скан и
`RoomBotListener`-слушатель) переезжают на одну и ту же VM и продолжают
работать с одними и теми же `config.json`/`state.json` на её диске —
команды в чате (`/price`, кнопки меню и т.п.) работают ровно как раньше,
никакие настройки не теряются.

**Какую VM взять бесплатно и насовсем** (не пробный период, а постоянный
бесплатный тариф):
- [Oracle Cloud «Always Free»](https://www.oracle.com/cloud/free/) —
  самый щедрый вариант (Ampere A1, до 4 OCPU / 24 ГБ RAM бесплатно
  навсегда).
- [Google Cloud «Always Free»](https://cloud.google.com/free) — 1
  инстанс `e2-micro` бесплатно навсегда (в регионах `us-*`).

**Шаги:**

1. Создай VM (Ubuntu/Debian) в одном из сервисов выше, подключись по SSH.
2. Поставь зависимости:
   ```
   sudo apt update && sudo apt install -y python3 python3-venv git
   ```
3. Скопируй проект на VM — например, через `scp` с локальной машины:
   ```
   scp -r room_bot <user>@<vm-ip>:/opt/room_bot
   ```
   (или `git clone`, если заведёшь для проекта репозиторий — необязательно).
4. Создай виртуальное окружение и поставь пакеты:
   ```
   cd /opt/room_bot
   python3 -m venv venv
   venv/bin/pip install -r requirements.txt
   ```
5. Заведи файл с секретами из шаблона `deploy/room-bot.env.example`:
   ```
   sudo cp deploy/room-bot.env.example /etc/room-bot.env
   sudo nano /etc/room-bot.env   # впиши настоящие TG_BOT_TOKEN и TG_MY_CHAT_ID
   sudo chmod 600 /etc/room-bot.env
   ```
6. Установи systemd-юниты из `deploy/` (поправь в них пути
   `WorkingDirectory`/`ExecStart`, если проект лежит не в `/opt/room_bot`):
   ```
   sudo cp deploy/room-bot-listener.service deploy/room-bot-scan.service deploy/room-bot-scan.timer /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now room-bot-listener room-bot-scan.timer
   ```
7. Проверь, что всё работает:
   ```
   systemctl status room-bot-listener
   systemctl list-timers room-bot-scan.timer
   journalctl -u room-bot-listener -f
   ```

`room-bot-listener` — постоянно работающий процесс (аналог
`RoomBotListener`), `room-bot-scan.timer` — таймер, запускающий скан
каждые 15 минут (та же частота, что и в `setup_room_bot.ps1`, аналог
задачи `RoomBot`).

## Тесты

Самая хрупкая часть кода — извлечение цены/адреса/метро из текста
объявления регулярками. Есть регрессионные тесты на неё в `tests/`:

```
pip install -r requirements-dev.txt
python -m pytest tests/
```

Стоит прогонять их после любой правки регулярок в `room_bot.py`.

## Важно

- Работает только с **публичными** каналами (у тебя все такие — ок).
- Не стоит запускать скрипт слишком часто (не чаще раза в 15-30 минут) —
  чтобы не получить временную блокировку от Telegram за частые запросы.
- `bot.log` пишется в UTF-8. Если открываешь его через `type` или
  `Get-Content` в обычной консоли PowerShell — кириллица может отображаться
  нечитаемыми символами. Смотри его в редакторе (VS Code, Notepad++) или
  через `Get-Content -Encoding UTF8`.
